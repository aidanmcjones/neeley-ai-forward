- `from agent.moat.case_footnotes import footnotes; footnotes(ticker, topic="all"|"litigation"|"royalty"|"contingent_consideration"|"tax_rate", docs=None, k=40)`: text-only extracts from the two latest annual reports plus the latest 10-Q or interim. Kinds: footnote (latest annual), latest_10q (no near match in the annual), dropped_from_latest (prior-year sentences with no match in the latest). Fields: text (verbatim, passes verify_quote), numbers, new_vs_prev, also_in_prev_year, prev_numbers, doc_year, topic, citation, url, locator. Limits: table rows skipped, so table-only figures are missed; NVO interim locators are #p1. CLI: `python -m agent.moat.case_footnotes TICKER [topic] [-k N]`. Doc: docs/research/case_retrieval/footnotes.md.
- `from agent.moat.case_segments import segment_changes; segment_changes(ticker, kind=None, k=200)`: kind in {restatement, discontinued_breakout, series_break, revenue_check, table_note}. restatement: same XBRL product/concept/period printed differently across filings (both values, pct_diff, class, explanation, cited to the 10-K page). discontinued_breakout: products no longer broken out, last value, folded into what, cited to last filing showing them and first not. series_break: two accessions disagreeing on one product/geography/period. table_note: keyword hits ("reclassified", "recast", "no longer separately") in latest 10-K and 10-Qs, many routine, judge each. Limit: restatement and discontinued_breakout only for the eight US filers; NVO and AZN get table notes only. CLI: `python -m agent.moat.case_segments TICKER [--kind restatement] [--k 20]`. Doc: docs/research/case_retrieval/segments.md.
- `from agent.moat.case_working_capital import working_capital; working_capital(ticker, quarters=12)`: kind="quarter" rows (US filers) with period_end, revenue and YoY, inventory and YoY, receivables and YoY, dso_days, dio_days, inventory_to_revenue_ttm, flags (inventory_outpaces_revenue, receivables_outpace_revenue, dso_up_10pct_yoy, restated), restated_from, citation to the balance-sheet page of the indexed 10-Q/10-K, else locator url:<companyfacts>#<concept>/<accn>. kind="annual" for IFRS filers (NVO, AZN, GSK, TAK, ALNY); NVS and SNY return []. kind="filing_note": management's own words on inventory, DSO, channel inventory, stocking, destocking. Caveat: cited balance-sheet page is keyword-found and can be off by one page; re-check with get_page before citing. CLI: `python -m agent.moat.case_working_capital TICKER`. Doc: docs/research/case_retrieval/working_capital.md.
- `from agent.moat.case_labels import label_compare; label_compare(drug, rivals=None, sections=("indications","boxed_warning","contraindications","warnings","rems","dosing","exclusivity","pricing"))`: drug is a case key (keytruda, skyrizi, vyndaqel...); rivals default to the case appendix list. Kinds: label_section (text, n_indications, has_boxed_warning, boxed_warning_terms, dosing_summary, label_effective, citation like "Keytruda label v228 (2026-07-24), p. 1 INDICATIONS", locator keytruda:drugs/keytruda/label_v228.md#p1), rems, label_change (latest 5), exclusivity (per territory from loe_calendar: Orange/Purple Book dates, company-stated LOE with 10-K page), pricing (gtn_exposure plus latest gtn_proxy year), head_to_head, and matrix (one per section, {drug: one-line summary}). Limits: generic placeholders have no label rows; imfinzi, tecentriq, cosentyx exclusivity rows being filled; vyndaqel falls back to the full current label; dosing_summary is regex, treat as a pointer and quote the label page. CLI: `python -m agent.moat.case_labels keytruda [--rivals opdivo imfinzi] [--section indications]`. Doc: docs/research/case_retrieval/labels.md.
- `from agent.moat.case_gtn import gtn_series; gtn_series(ticker=None, drug=None, k=200)`: kinds company_list_vs_net (average list vs net price change per year, cited to the company's pricing transparency report page), drug_gtn_exposure, drug_gtn_proxy (Part D spend per unit, ASP, NADAC, ratios), wac_event, nadac, partd_support, partb_asp, filing_sales_deduction_table (10-K gross-to-net reconciliation excerpt, e.g. BMY and PFE), filing_statement (10-K/10-Q/transcript sentences, transcripts grade B+, all pass verify_quote). Rows carry period, value, unit, verify_status, source, source_row, locator. verify_status unverified_raw (wac_event, nadac, partd_support, partb_asp) and unreliable_raw (column-shifted 2020 WAC rows, value None) are machine_data at best under the gate: never quote or deep-link them publicly. keytruda also returns keytruda-qlex. CLI: `python -m agent.moat.case_gtn MRK` or `--drug keytruda`. Doc: docs/research/case_retrieval/gtn.md.
- `from agent.moat.case_calls import call_qa, dropped_metrics`. `call_qa(ticker, quarters=4, flags=("deflection","new_phrase","never_asked"), grade_min="C", k=80)`: one best call per quarter (A, then B, then C; Bloomberg docs carry license bloomberg_licensed, cite by label only). Kinds: qa_pair (quarter, speaker, firm, question, answer, deflection_score 0 to 1 with reasons, citation to the answer page, quotable = grade A or B), new_phrase (terms in the latest call absent from the prior three; grade C can produce misspelled false positives), never_asked (topics analysts have not asked about). `dropped_metrics(ticker, releases=6)`: labels in at least 2 earlier releases, slides or 10-Q product tables and absent from the latest two, with last-seen citation; noisy (one-off items, Q4-only labels). Only quote qa_pair rows with quotable true. CLI: `python -m agent.moat.case_calls MRK [--quarters 4] [--grade C] [-k 20] [--dropped]`. Doc: docs/research/case_retrieval/calls.md.

- `from agent.moat.case_risk_diff import risk_diff; risk_diff(ticker, section="risk_factors"|"mdna"|"both", fy=None, prev=None, k=60, min_chars=80)`: kinds added, removed, changed (sentence pairs with word-level diff "-[old] +[new]", similarity, salience, flags), plus a section_stats row per section. CLI: `python -m agent.moat.case_risk_diff MRK [--section both] [--fy 2025] [--prev 2024]`. Doc: docs/research/case_retrieval/risk_diff.md.
