# ui/public/data

Regenerate from the repo root:

```
PYTHONPATH=. python -m agent.ui_export
```

Notes: `stance.generated_by` is `template` (no ANTHROPIC_API_KEY at export). Excerpts are about 900 characters either side of the quote (600 if a company file would exceed 4 MB). Onboarded tickers without findings are listed in meta.onboarding_pending and get no company file.

Engine: v2 (out/<T>/findings_v2.jsonl, rejected_v2.jsonl, out/league_v2.json) when present, else v1. Public rule: a citation that is unverified or Bloomberg-licensed exports no quote, excerpt, deep link or viewer link (`withheld: true` + reason); WRDS-licensed data rows are summarised in `licensed_inputs` (count and table names only).
