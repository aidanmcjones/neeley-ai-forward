Corpus downloads

Documents the scripts could not fetch because the sites block automated downloads. Open each link in your browser and save the file.

How it works
  1. Save every file into this folder: C:\Users\parke\OneDrive\Desktop\Hackathon\neeley-ai-forward\data\corpus\_inbox\
  2. Format: PDF. If a page has no PDF, save the web page as .html (Ctrl+S, "Webpage, HTML only").
  3. Rename it to the exact name in the "Save as" column.
  4. Tell Claude "ingest the inbox". It runs python -m agent.ingest_inbox, adds page markers, files each document in the right folder, and refreshes the gap report.

If a link goes to a page that no longer exists, go to the company's investor site, then Events & Presentations or Quarterly Results, and find the quarter.

After we pick a company: official transcripts

Pull the official transcripts for our company's last 4 calls from Bloomberg / FactSet / Capital IQ and add a source tag so they replace the free-site copies. The old copy is kept as ..._thirdparty.md.

Example: BMY_transcript_2026Q2_bloomberg.pdf. Source tags: bloomberg, factset, capiq, refinitiv.

Already official, no action needed: Merck, Pfizer, J&J (all quarters); Sanofi Q1/Q2 2026; GSK Q2 2025, Q3 2025, Q1 2026.

Naming rule

TICKER_kind_period[_source].pdf. kind is one of transcript, slides, presentation, report or press. period looks like 2026Q2, or a short label such as 2026-01-jpm. Tickers: MRK BMY PFE LLY NVO ABBV JNJ AZN AMGN GILD NVS GSK SNY TAK REGN ALNY BBIO ROCHE BOEHRINGER.
